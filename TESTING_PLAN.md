# План тестирования FilamentHub OrcaSlicer клиента

## Цель
Провести ручное тестирование всех функций интеграции FilamentHub с OrcaSlicer через Playwright MCP и исправить найденные ошибки.

## Области тестирования

### 1. Авторизация и управление сессией
- [ ] Вход через WebView (логин/пароль)
- [ ] Сохранение токена в AppConfig
- [ ] Автоматическая синхронизация после логина
- [ ] Обработка истечения токена (401)
- [ ] Выход из системы (logout)
- [ ] Проверка состояния авторизации при загрузке панели

### 2. Синхронизация пресетов филамента
- [ ] Полная синхронизация (force_full_sync = true)
- [ ] Инкрементальная синхронизация (force_full_sync = false)
- [ ] Импорт новых пресетов из FilamentHub
- [ ] Обновление существующих пресетов
- [ ] Обнаружение удаленных пресетов (локально удалены, но есть на сервере)
- [ ] Обработка ошибок (401, 403, 500)
- [ ] Проверка маппингов (preset_id → bundle_preset_name)
- [ ] Сохранение маппингов в AppConfig

### 3. Экспорт пресетов филамента
- [ ] Экспорт всех пользовательских пресетов
- [ ] Проверка разрешения allow_filament_presets_import
- [ ] Отправка пресетов на сервер через POST /orcaslicer/presets/import
- [ ] Обработка ответа (created/updated/error)
- [ ] Сохранение маппингов (external_id → fhub_id)
- [ ] Уведомления об успехе/ошибке

### 4. Синхронизация профилей принтеров
- [ ] Автоматическая синхронизация после синхронизации пресетов
- [ ] Импорт новых профилей принтеров
- [ ] Обновление существующих профилей
- [ ] Проверка маппингов (printer_profile_id → bundle_printer_profile_name)
- [ ] Обработка ошибок

### 5. Экспорт профилей принтеров

- [ ] Сохранение маппингов

### 6. Синхронизация профилей печати
- [ ] Автоматическая синхронизация после синхронизации пресетов
- [ ] Импорт новых профилей печати

## Сценарии тестирования

### Сценарий 1: Первый запуск (новый пользователь)
1. Открыть FilamentHub панель в OrcaSlicer
2. Войти через WebView
3. Проверить автоматическую синхронизацию
4. Проверить импорт пресетов
5. Проверить сохранение маппингов

### Сценарий 2: Повторная синхронизация
1. Войти в систему
2. Нажать кнопку синхронизации
3. Проверить инкрементальную синхронизацию
4. Проверить обновление существующих пресетов

### Сценарий 3: Экспорт пресетов
1. Создать новый пресет филамента в OrcaSlicer
2. Нажать кнопку "Из OrcaSlicer" на сайте
3. Проверить отправку пресета на сервер
4. Проверить сохранение маппинга

### Сценарий 4: Обработка удаленных пресетов
1. Синхронизировать пресеты
2. Удалить пресет локально в OrcaSlicer
3. Синхронизировать снова
4. Проверить обнаружение удаленного пресета
5. Проверить отправку на сервер

### Сценарий 5: Истечение токена
1. Войти в систему
2. Подождать истечения токена (или изменить токен вручную)
3. Попытаться синхронизировать
4. Проверить обработку 401 ошибки
5. Проверить автоматический logout

## Инструменты тестирования

### Playwright MCP
- Открытие WebView в браузере
- Взаимодействие с UI (клики, заполнение форм)
- Скриншоты для документации
- Проверка элементов и текста
- Логи браузера

### Ручное тестирование
- Проверка логов OrcaSlicer (BOOST_LOG_TRIVIAL)
- Проверка AppConfig (сохранение токенов и маппингов)
- Проверка PresetBundle (импортированные пресеты)

## Критерии успеха

- ✅ Все функции работают без ошибок
- ✅ Обработка ошибок корректна
- ✅ UI обновляется правильно
- ✅ Маппинги сохраняются и загружаются корректно
- ✅ Синхронизация работает быстро и надежно
- ✅ Нет утечек памяти или deadlock'ов

## Известные проблемы для проверки

1. **Счетчик активных синхронизаций** - проверить, что `m_active_syncs` правильно увеличивается/уменьшается
2. **Обработка пустых списков** - проверить, что пустые ответы от API обрабатываются корректно
3. **Маппинги** - проверить, что маппинги не теряются при перезапуске
4. **Thread safety** - проверить, что нет race conditions при одновременных операциях
